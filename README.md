# Historian Analytics Engine for Industrial Process Intelligence

## Overview

Historian Analytics Engine is a research-oriented project that analyzes industrial historian data to automatically extract operational intelligence from industrial processes.

The project focuses on understanding industrial systems directly from historical process data generated by sensors, actuators, PLCs, and SCADA systems.

By analyzing historian data, the system aims to:

- Identify industrial assets
- Classify sensors and actuators
- Discover operating characteristics
- Infer relationships between assets
- Reconstruct process knowledge
- Detect anomalies
- Support industrial analytics and OT security applications

The long-term vision is to build a software platform capable of learning how an industrial process operates using only historian data.

---

## Motivation

Modern industrial facilities continuously generate large volumes of operational data.

This data is typically stored in industrial historians and contains valuable information about:

- Process behavior
- Equipment operation
- Control actions
- Plant performance
- System health

Despite this, much of the process knowledge remains undocumented and requires manual interpretation by domain experts.

This project explores how data analytics and machine learning can be used to automatically discover and model that knowledge.

---

## Dataset

Development currently uses the **SWaT (Secure Water Treatment)** dataset, which contains historian-style process data from a water treatment system.

The dataset includes information from:

- Pumps
- Valves
- Flow Sensors
- Level Sensors
- Pressure Sensors
- Water treatment process stages

Future versions may support additional industrial datasets and custom historian exports.

## Current Capabilities

### Asset Inventory Generation

Automatically extracts industrial assets from historian data.

Example:

| Asset |
|---------|
| FIT101 |
| LIT101 |
| MV101 |
| P101 |

---

### Asset Classification

Identifies asset types based on industrial tag naming conventions.

Example:

| Asset | Type |
|---------|---------|
| FIT101 | Flow Indicator Transmitter |
| LIT101 | Level Indicator Transmitter |
| MV101 | Motorized Valve |
| P101 | Pump |

---

### Asset Metadata Extraction

Extracts information such as:

- Asset identifier
- Asset category
- Process stage
- Tag structure
